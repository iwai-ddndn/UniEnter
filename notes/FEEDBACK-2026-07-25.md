## P0: 実害が出たもの

### 1. macOS 15 でインストールできない(2名が脱落)

- 環境: MacBook Pro M1 2020 / macOS Sequoia 15.3.2 と 15.4 の2台とも
- 症状: pkg・zipどちらも「"UniEnter"は開けません。Appleは…マルウェアが
  含まれていないことを確認できませんでした」→ 選択肢は「完了」「ゴミ箱に入れる」のみ
- 原因: 未公証。加えて **macOS 15 以降は Finder で右クリック →「開く」の回避策が廃止**され、
  システム設定からの解除が唯一の経路になっている
- 旧LPのFAQは方向としては正しかったが、(a) アコーディオンの最下部に埋もれていた
  (b) 「先に一度開こうとする必要がある」ことが書かれていなかった (c) 右クリック回避策が
  使えないことに触れていなかった

**対応(済)**: LPに独立した「インストール手順」セクションを新設。3ステップ+つまずきポイントを明記。
ヒーローのDLボタン直下から導線を張った。

**根本対応(未・ユーザー作業)**: Apple Developer Program 加入 → Developer ID署名 + 公証。
これが済むまで、告知して広く配ると同じ脱落が繰り返される。**公証は公開前の必須条件**。

### 2. LINEで⌘Enterを押しても送信できない

- 症状: 「LINEデスクトップ版で⌘Enterしたら改行になってしまって送れない」
- 原因: LINE側で既に「⌘Enterで送信」に設定していた。UniEnterが ⌘Enter→Enter に変換し、
  LINEはEnterを改行として扱うため送信されない
- アプリには対処設定(旧「詳細オプション: アプリ側の送信キー」)があったが機能していなかった:
  - 「詳細オプション」という名前では、困った人がそこに辿り着けない
  - プルダウンの既定が「Enter」で、**「例外的にEnterで送信するアプリを選ぶ欄」と誤読された**
  - そもそも「わざわざアプリ側を⌘Enterに設定済みの人」＝本製品の中心顧客であり、
    その層が既定設定のまま壊れる

**対応(済)**:
- 見出しを症状ベースに変更: 「⌘Enterを押しても送信できないときは」
- プルダウン(Enter / ⌘Enter)を廃止し、チェックボックス「アプリ側で、送信キーを⌘Enterに変更済み」に
- チュートリアル2ページ目に事前告知を追加
- LP FAQに「アプリ側の設定と、どちらが優先される?」「⌘Enterを押しても送信できない」を追加

## P1: 価値が伝わらない

- 「改行と送信を統一」→ 「一つのボタンでどっちもできるってこと?と一瞬思った」
- 「どのアプリがどっちで、どのくらいのペインが取り除かれるのかわかるとありがたみが伝わりそう」
- 「どのくらい今がダルくて、入れることによってどのくらい楽になるのかが想像つかない」
- 刺さった表現: 「『うっかり送信』をなくします」/ 提案「改行と送信、もう間違えない。」
- 最も強い価値: 「メッセージアプリ側の設定画面とか一切開かずに、これ立ち上げてるだけで
  脳死で⌘エンターになってくれるなら本当にありがたい。2度と設定画面を見たくないから」

**対応(済)**: ヒーローH1を「改行と送信、もう間違えない。」に変更し、痛みの描写を先に置いた。
Before/Afterセクションを新設し、「各アプリの設定画面は、もう開かなくていい」を明示。

## P2: 文言(すべて対応済)

| 箇所 | 指摘 | 対応 |
| --- | --- | --- |
| 「軽くて、何も送らない」 | 2要素が1枠で分かりづらい / 羽の画像が「送らない」に掛からない | 「入れていることを、忘れる軽さ」に分離し、プライバシーは独立ブロックへ |
| 「日本語入力に、とことん安全」 | 何のことか分からない・日本語が歪 | 「変換中のEnterには、触れません」 |
| 「フェイルセーフ設計」「〜側に倒す」 | 専門用語でピンとこない | 平易化 |
| FAQの疑問文が不統一 | 「アプリ側で『⌘Enterで送信』にしている」等 | 全項目を疑問文に統一 |
| 「入力内容を読まれない?」 | 「サーバーに送信されない?」の方が具体的 / 「Enter関連のキー」が曖昧 | 「入力した文章が、どこかに送られない?」+ EnterとCommandの2つと明記 |
| 「何台のMacで使える?」 | 台数を聞く前に「複数台で使えるか」を知りたい | 「複数台のMacで使える?」 |
| 「2回目以降は普通に開けます」 | ラフすぎる | 「警告なしで開けます」 |
| 「書き換え」全般 | 「入力文章を書き換える」と誤読されうる | 「Enterキーの切り替え」等に置換 |
| 設定「チェックしたところで」 | 不自然 | 「チェックを入れたところが、〜になります」 |

## P3: UI・挙動(対応済)

- 詳細オプション展開時に「ブラウザ版はSafari〜」が「…」で見切れる
  → ウィンドウが内容に追従していなかった。`NSHostingController.sizingOptions` で解決
- トライアル期限切れの通知がない(「気づかず入れっぱなしの謎アプリは最悪」)
  → 期限切れに変わった瞬間にライセンス画面を開くようにした。文面に「使わない場合は削除して
  かまいません」を追加
- アプリ容量が気になる → FAQに「約3MB」を明記
