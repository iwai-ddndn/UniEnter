# UniEnter リリース告知プラン(統合版)

作成日: 2026-07-23
本ファイルが最新の正。`launch/LAUNCH-PLAN.md`(カラー版・7/22)と `launch-monochrome/LAUNCH-PLAN.md`(モノクロ版・7/23)の2案を検討し、統合・修正したもの。

## 旧2案からの主な変更点

1. **URLを本番ドメインに統一**: 旧案は全て `iwai-ddndn.github.io/UniEnter/` を使用していたが、LPは `https://unienter.oc-to.com/` に移行済み。リダイレクト経由はUTM欠落やカード生成の不安定要因になるため、投稿には必ず本番ドメインを使う。
2. **素材はカラー版(`launch/assets/`)を採用**: LPは白背景+改行グリーン(#0f7b6c)/送信ブルー(#2383e2)のトーン。「投稿→LPに移った瞬間に同じ製品と認識できる」というプラン自身の原則に照らすと、モノクロ版はLPとの一貫性を欠く。モノクロ版(`launch-monochrome/assets/`)は代替・別文脈用(技術記事など)として保持。
3. **投稿時刻はモノクロ版の分析を採用**: 火曜 21:05 JST(国内調査の夜ピーク根拠)。カラー版の20:30仮説より根拠が強い。
4. **日付は「アンカー方式」に変更**: 旧案の 7/28 公開は、GO条件のうち Paddle 決済と Developer ID 公証が未達(ユーザー作業待ち)のため現状では成立しない。「GO条件が月曜までに揃った週の火曜に公開」とし、揃わなければ1週間単位でスライドする。

- [ ] `.pkg` / `.zip` のダウンロードと初回権限フローを第三者環境で確認済み
- [x] LP が本番ドメインで公開済み(unienter.oc-to.com)
- [x] 利用規約・プライバシーポリシー・問い合わせ先が到達可能
- [x] OG/Twitterカードのメタタグ設置済み(2026-07-23 修正: 絶対URL化+twitter:card追加)→ **投稿前に [X Card Validator や実アカウントのDM等で本番URLの表示を実機確認](https://cards-dev.twitter.com/validator)**

公証前に人に見せる場合は「正式リリース」と言わず、知人5〜10人の先行テストに限定する。
